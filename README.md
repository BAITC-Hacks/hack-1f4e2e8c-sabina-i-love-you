# Есть дефект или нет

Минимальный классификатор для хакатонного задания: по одному PNG-изображению скрипт выводит `OK` или `DEFECT`.

Правило намеренно простое и прозрачное: пиксель считается красным, если его красный канал больше 180 и заметно сильнее зелёного и синего. Если красных пикселей не меньше 30% от изображения, выводится `DEFECT`; в противном случае — `OK`.

## Запуск

Нужен Python 3.9+; внешние библиотеки не требуются.

```powershell
py classify.py ok.png
# OK

py classify.py defect.png
# DEFECT
```

Порог можно изменить при необходимости:

```powershell
py classify.py photo.png --threshold 0.45
```

В репозитории есть два проверочных изображения: `ok.png` (зелёный квадрат) и `defect.png` (красный квадрат). Скрипт поддерживает обычные 8-битные PNG в RGB/RGBA без чересстрочной развёртки.

В macOS/Linux вместо `py` обычно используется `python3`.
